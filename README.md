# 🍌 Analisis Kualitas Pisang menggunakan Orange Data Mining

Saya mencoba menganalisis data kulitas Pisang dengan menggunakan software Orange Data Mining 📊📌

Proyek ini menganalisis **kualitas buah pisang** berdasarkan berbagai faktor seperti tingkat kematangan, kadar gula, dan tekstur menggunakan "Orange Data Mining".

## 🎯 Tujuan
Mengetahui hubungan antara variabel-variabel yang mempengaruhi kualitas pisang dan membuat model klasifikasi untuk memprediksi kategori kualitasnya.


## 🧰 Tools yang digunakan
- Orange Data Mining
- Dataset kualitas pisang (`.csv`)
- Visualisasi ROC, Confusion Matrix, dan Scatter Plot


## 📊 Hasil Analisis
Beberapa model klasifikasi telah dibandingkan untuk melihat performanya dalam memprediksi kualitas pisang.  
Setiap model menunjukkan hasil akurasi yang berbeda, dengan variasi performa tergantung pada kombinasi fitur yang digunakan.
